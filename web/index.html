FAQ

A few useful details

How is my data protected?

Tab Sync syncs the URLs, titles, and state of your regular open tabs and recent navigation, so it can show them on your other connected browsers. Private and incognito tabs are excluded. We do not read page contents, passwords, or form fields.

Can I self-host Tab Sync?

Yes. Tab Sync is open source and built to run on your own server. The repository includes the app, extensions, and deployment guidance to get you running.

What’s the business model?

Currently, there isn’t one. Tab Sync is free to use. We may introduce a paid plan later, but anyone using Tab Sync before that happens will be grandfathered in.

Which browsers work?

Chrome and Firefox have store extensions. Safari is available from the extensions repository, including projects for macOS, iPhone, and iPad.

Will it restore or close tabs for me?

No. Tab Sync is deliberately read-only: it lets you find and open tabs from another browser without rearranging anything where you are.

Safari on macOS

  1. Clone the extensions repository.
  2. Open safari/Tab Sync for macOS/Tab Sync for macOS.xcodeproj in Xcode.
  3. Select your development team, choose My Mac, then run the project.
  4. Enable Tab Sync in Safari’s extension settings and sign in from the toolbar.

Safari on iPhone or iPad

  1. Clone the extensions repository.
  2. Open safari/Tab Sync/Tab Sync.xcodeproj in Xcode.
  3. Connect your iPhone, select it as the destination, and run the project.
  4. Enable Tab Sync in Safari’s extension settings.

Publishing a Safari extension requires a paid Apple Developer subscription. I’m skipping that cost for now, so Safari is installed from source.
