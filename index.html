Safari on iPhone

  1. Clone the extensions repository.
  2. Open safari/Tab Sync/Tab Sync.xcodeproj in Xcode.
  3. Connect your iPhone, select it as the destination, and run the project.
  4. Enable Tab Sync in Safari’s extension settings.

Publishing a Safari extension requires a paid Apple Developer subscription. I’m skipping that cost for now, so Safari is installed from source.

Need help? Ask on GitHub or email tabsync@nkson.com.
